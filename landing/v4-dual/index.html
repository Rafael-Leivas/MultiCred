// Segurança //

Mexe no mínimo. Nunca nos seus segredos.

✓ O que o app altera

  • Um bloco marcado # >>> MultiCred >>> no fim do ~/.zshrc, bash e gitconfig
  • A conta ativa do gh, via gh auth switch
  • CLAUDE_CONFIG_DIR para apps gráficos
  • Itens app.multicred.apikey no Keychain

✕ O que nunca toca

  • Tokens do Claude Code e do gh
  • O conteúdo das pastas ~/.claude*
  • O hosts.yml do gh (só via gh)
  • Qualquer linha dos seus arquivos fora do bloco do MultiCred

🔒 Desinstalação limpa

Ajustes › Desinstalar remove só os blocos, o arquivo do fish, a variável do launchd, as chaves do Keychain e a pasta do app. Os backups vão para MultiCred-backups-<data> e suas contas continuam logadas nas próprias ferramentas.

// FAQ //

Perguntas frequentes.

O MultiCred lê ou copia meus tokens?

Não. Ele só aponta CLAUDE_CONFIG_DIR para a pasta certa e usa gh auth switch. O login acontece no navegador, pelo próprio Claude Code. Os valores das chaves de API ficam no Keychain.

Preciso reiniciar o terminal depois de trocar?

Abra um novo Terminal. Sessões do Claude Code já abertas continuam na conta anterior, e o app avisa quantas são.

Funciona com zsh, bash e fish?

Sim. O app detecta o shell ativo e mostra os arquivos reais que vai alterar antes de aplicar.

E se eu usava meus scripts antigos?

O onboarding detecta a versão antiga, oferece remover as linhas e importa as suas configurações.

Como desinstalo?

Ajustes › Desinstalar. Só os blocos marcados são removidos e os backups ficam salvos numa pasta com a data.
