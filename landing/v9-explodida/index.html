FOLHA 6 — NOTAS DE RODAPÉ DA PRANCHA

Perguntas frequentes.

NOTA 1 O MultiCred lê ou copia meus tokens?

Não. Ele só aponta CLAUDE_CONFIG_DIR para a pasta certa e usa gh auth switch. O login acontece no navegador, pelo próprio Claude Code. Os valores das chaves de API ficam no Keychain.

NOTA 2 Preciso reiniciar o terminal depois de trocar?

Abra um novo Terminal. Sessões do Claude Code já abertas continuam na conta anterior, e o app avisa quantas são.

NOTA 3 Funciona com zsh, bash e fish?

Sim. O app detecta o shell ativo e mostra os arquivos reais que vai alterar antes de aplicar.

NOTA 4 E se eu usava meus scripts antigos?

O onboarding detecta a versão antiga, oferece remover as linhas e importa as suas configurações.

NOTA 5 Como desinstalo?

Ajustes › Desinstalar. Só os blocos marcados são removidos e os backups ficam salvos numa pasta com a data.
